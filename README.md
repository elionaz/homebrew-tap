# elionaz/homebrew-tap

Homebrew tap for [agenterm](https://github.com/elionaz/agenterm), a desktop workspace for coding agents organized by project.

```sh
brew install --cask elionaz/tap/agenterm
```

The cask in `Casks/` is updated automatically by agenterm's release workflow.
